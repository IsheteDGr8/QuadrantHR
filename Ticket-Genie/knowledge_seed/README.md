# Northstar Technologies policy starter pack

These fictional, enterprise-style policies seed TicketGenie's company-wide (`General`) knowledge scope. They are templates for demonstration—not legal, tax, benefits, or employment advice. An authorized Admin or Ticketer should review organization-specific values before uploading them through the Knowledge Base screen.

Upload each Markdown file with the displayed title and the **Company-wide policy** scope. Source files remain private in Blob Storage; employees receive answers only through Genie.
